# UsageLeaf releases

Signed Windows installers and the update manifest for UsageLeaf by Garda Studio.

Download the latest installer from [Releases](https://github.com/Garda-Studio/usageleaf-releases/releases/latest). Installed copies check `latest.json` from the latest release and install only updates signed with the UsageLeaf key.
